# Python Automation Scripts

Welcome to my Python script repository. This space tracks the core automated components, text processing algorithms, and logic tools I am building to streamline system tasks and manage infrastructure configurations.

Currently, it hosts a deep dive into Python's core data structures, concentrating heavily on raw text engineering, sequence manipulation, input/output verification structures, and memory slicing mechanisms.

---

## 📂 Script Inventory & Breakdown

### 1. Core Module: string_manipulation_basics.py
This module serves as a foundation layout covering Python memory handling, raw string evaluation, and user input data transformations.
* **Dynamic I/O & Type-Casting:** Runtime console input processing, verification logic using logical constraints (`is`, `in`), and functional casting mechanics converting string data streams into integer parameters (`int()`).
* **Advanced Memory Slicing:** Multi-directional parsing matrices covering target index boundaries, positive extraction limits (`[0:3]`), and reverse indexing strides (`[-1::-2]`) for parsing raw string streams.
* **Whitespace & Sanitization Engineering:** Functional tracking tools mapping text cleanup processes using `.strip()`, `.lstrip()`, and `.rstrip()` methods to optimize data cleanliness before transmission.
* **String Structural Alteration:** Automation tools built for string reconstruction pipelines, implementing character-mapping changes (`.replace()`), targeted character splittings (`.split(':')`), and array-to-string layout transformations (`"_".join()`).
* **Boolean Evaluation Methods:** Direct sanity validation constraints verifying memory contents with structural string definitions including `.isalpha()`, `.isdigit()`, `.isalnum()`, `.islower()`, and `.isupper()`.

### 2. Core Module: tuple_structures_and_methods.py
This module tracks operations on immutable sequences, structural integrity testing, and multi-dimensional matrix boundary navigation.
* **Immutable Data Integrity:** Tracking static data blocks using fixed index boundaries, occurrence counters (`.count()`), and reference positions (`.index()`).
* **Nested Coordinate Slicing:** Extracting target character subsets directly out of string sequences encapsulated inside specific tuple coordinates (e.g., `a[3][2:5]`).
* **Sequence Transformations:** Reversing sequence orders via negative strides (`[-1::-1]`) and demonstrating delimited data parsing via character joining and splitting methods.

### 3. Core Module: list_practice.py
This module demonstrates working with mutable sequences, multi-directional indexing layouts, and dynamic, interactive terminal input validation.
* **Sequence Striders & Operations:** Evaluates indexing lookup behaviors, element counts, tracking forward/reverse list boundaries, and list concatenation.
* **Case & Boundary Verification:** Running automated boolean checks (`.islower()`, `.isupper()`) and modifying text states (`.swapcase()`, `.upper()`) across variable array fields.
* **Interactive Run-Time Validation:** Captures live console parameter strings and user-defined index constraints (`int(input())`) to validate runtime array matches dynamically.
